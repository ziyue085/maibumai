# 案例一：合理享受型消费

> 这类案例是本 Skill 的立场试金石。**能不能在该支持的时候干脆支持，比能不能劝退更难。**

## 用户输入

> 万能青年旅店 12 月来济南，内场 680。我听了五年了，但是不是有点贵？

## 判断过程

**分级**：680 元，品类"演出/门票" → L3（超过单笔门槛 500）。

**已有物品**：不适用。

**需求诊断**：零提问。用户已经给了三个关键信息——
- 听了五年（需求先于接触存在）
- 巡演（稀缺，不是随时能补）
- 明确说"我听了五年"（情感来源具体）

再问"你为什么想去"就是浪费他的时间。

**取证**：官方票务页档位 680，在售。同一巡演其他城市内场 680–880，价格一致，无溢价。

**算术**：体验型消费**不算单次成本**（680 元看一场，"每次 680 元"没有信息量）。

占月可支配 34%。

**判定理由码**：

| 码 | 依据 |
|---|---|
| `NEED_REAL` | 听了五年，巡演到本地，需求先于票价存在 |
| `EMOTIONAL_VALUE_LEGIT` | 情感来源具体（五年、现场），非"跟风/拍照"；预算内；无重复 |
| `AFFORDABLE_WITHIN_BUDGET` | 占月可支配 34%，不挤占刚性支出 |

→ **建议购买**

## 输出

```
【结论】建议购买

【一句话】买。听了五年，巡演到济南，这个价没有溢价——这种钱花得值。

【为什么】
· 需求真实：听了五年，不是刷到才想去的 —— NEED_REAL
· 情绪价值成立：现场体验，来源具体，不是跟风 —— EMOTIONAL_VALUE_LEGIT
· 在预算内：680 元占月可支配 34%，不影响这个月的其他安排 —— AFFORDABLE_WITHIN_BUDGET

【账】
体验型消费不算单次成本——花 680 看一场，按次数摊是算不出意义的。
实际支出记得算上交通和周边，大概 900 上下。

【证据】
官方票务 680 元（2026-10-28），其他城市同档 680–880，无溢价。
```

## 这个案例在防什么

**防"过度理性"**。一个只会算账的系统会在这里说：

> 680 元看三个小时，每小时 227 元，性价比不高，建议在家听专辑。

这是错的。它把体验消费当成了耐用品，用错了框架。**情绪价值是可命名的正当价值，不是需要被折现的负债。**

## 判定要点

`EMOTIONAL_VALUE_LEGIT` 有四条门槛，缺一不可：

1. 情感来源具体 → "听了五年" ✅
2. 不是"好看/便宜/别人都有" ✅
3. 预算内 ✅
4. 不与已有物品重复 ✅

如果用户说的是"最近这个乐队很火，好像大家都去"，第 1 条不成立 → 那其实是 `IMPULSE_SIGNAL`，结论应该变成暂缓。
