# 案例五：同一个问题，有画像和没画像的差别

> 这个案例展示 v0.2 的核心：**判断落在具体的人身上，而不是"一般人应该怎样"。**

## 用户输入

> 看中一台二手富士 X-T4，机身加镜头 6800，我最近很想学摄影，值不值？

## 没有画像时，通常得到的回答

> 富士 X-T4 是很好的机器，二手 6800 属于正常区间，如果你确实热爱摄影，值得入手。
> 建议根据自身预算决定。

问题不在结论，在于**它没有回答"我"该不该买**——6800 对一个人是两个月零花，对另一个人是全部积蓄。

## 有画像时

`mbm.py brief` 给出：

```
月收入 2600｜固定支出 1100｜储蓄目标 300｜月投资 400
→ 月可支配 约 800 元
可投资本金 30000｜应急金 6000｜单笔硬上限 3000
主目标：换相机（每月 300 元）
长期兴趣：编程、AI、摄影
```

三个数字直接改变判断：

| 数字 | 含义 |
|---|---|
| 可支配 800 | 6800 = **8.5 个月的全部可支配余额** |
| 硬上限 3000 | 6800 是上限的 **2.3 倍**，触发强制否决 |
| 目标「换相机」每月 300 | 这笔钱等于把目标推后 **22 个月** |

**结论被引擎强制为「不建议购买」**——不是模型觉得贵，是用户自己划的线被越过了。
模型没有裁量权：只要价格超过 `hard_cap_single`，无论理由多充分都不给购买。

## 输出

```
【结论】不建议购买

【一句话】不是让你别学摄影，是这台机器的价位越了你自己划的那条线。

【为什么】
· 超过你设的单笔上限：6800 是你的 3000 上限的 2.3 倍
· 等于 8.5 个月的全部可支配余额（每月 800）
· 相机目标每月存 300，这笔钱等于把目标推后 22 个月
· 二手无保修：镜头型号、快门数、成色、是否国行都还不知道

【账】
6800 ÷（每月 3 次 × 24 个月）≈ 单次 94 元
按你设的 8% 定投预期，10 年后是 14681 元

【想学摄影，可以这样开始】
① 这一个月先用手上的手机和 iPad 拍，或者租台富士玩两周
② 真要入手，3000 以内的二手 X-T30 够练构图和曝光
③ 实在想要这台：先要到镜头型号和快门数，同城当面验机
```

## 这个案例在防什么

**防两种相反的错**：

1. **通用建议**——"二手 6800 价格正常，值得入手"。它没错，但它没在回答这个人的问题。
2. **身份偏见**——"你是学生，别买这么贵的"。这不叫判断，叫贴标签。

正确的做法是第三条路：**把身份换成一个数，让数说话。**

- 不说"学生没钱"，说"这等于你 8.5 个月的可支配余额"
- 不说"要理性消费"，说"你自己划的线是 3000"
- 不说"先别买"，说"3000 以内有 X-T30 这条路径"

## 判定要点

1. **硬上限优先于一切**。用户自己设的线，比任何性价比论证都高。
2. **兴趣不影响硬约束**。摄影是真实兴趣，但兴趣不能让 6800 变成 3000。
3. **给可执行的下一步**，不是只否决。先租、先用手上的、降一档——三条都比"再想想"有用。
4. **机会成本只在用户设了收益率时才算**。没设就不出现"十年后是多少"，绝不替他假设 8%。
