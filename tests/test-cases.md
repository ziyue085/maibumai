# 测试用例说明

## 一、设计原则

每条用例都对应一个真实会发生的场景，不是为凑覆盖率编的。

判断一条用例好不好，问三个问题：

1. 这个场景真实存在吗？
2. 如果系统在这里出错，用户会受损吗？
3. 出错的表现是什么？能不能写成断言？

第 3 条最关键。写不成断言的，只能进人工回归清单。

**断言用精确匹配**：除了 `expect` 里列出的码，不允许出现别的阻断；确有合理附带项的，必须在 `allow` 里显式声明。v0.1 用的是"包含"断言，结果新加的阻断码可以悄悄出现而不被发现——审核为此扣了分。

## 二、五层分工

| 层 | 文件 | 测什么 | 数量 |
|---|---|---|---|
| verdict | `cases/verdict_cases.json` | 规则码 → 结论是否正确 | 20 |
| audit | `cases/audit_cases.json` | 结论是否自洽、具体、可核验 | 17 |
| evidence | `cases/evidence_cases.json` | 来源、时效、币种、数值合法性 | 17 |
| calc | `cases/calc_cases.json` | 算术、分级、财务约束 | 22 |
| pipeline | `cases/pipeline_cases.json` | 跨模块全链路 | 18 |

pipeline 是 v0.2 新增的一层，因为审核发现的十个问题里有六个**单模块测不出来**——它们是模块之间的接头处：财务算了但没人用、等级能被改、币种没归一、强制码被丢掉。

## 三、重点关注

| 场景 | 用例 | 断言 |
|---|---|---|
| **合理享受型消费** | V01、V02 | 必须给出"建议购买"，判成暂缓即失败 |
| **冲动消费** | V03、V11、V15 | 必须拦下或暂缓 |
| **信息不足** | V11、V16、A01、A08 | 暂缓 + 必须有复查条件 |
| **价格过期** | V09、E02、E10、A11、P13 | 过期价格不得支撑购买结论；但作为暂缓理由不算缺陷 |
| **错误推荐** | V05、V14、A02、A06、A07 | 不得推荐错误型号，不得凭口述价断言价格合理 |
| **财务强制** | P01、P02、P03、P16 | 超标必须改结论，不许模型自由裁量 |
| **外币** | P05、P06 | 没汇率就阻断，有汇率才比较 |
| **订阅周期** | C16–C19、C22、P07、P08、A17 | 月付不能按次摊，缺周期必须阻断 |
| **等级绕过** | A15、P04 | 只能往上调，不能往下调 |

## 四、反向对照（防"一律拦截"）

一个永远输出"不建议购买"的系统也能通过所有拦截测试。所以：

- **V01/V02**：合格的享受型消费必须放行
- **A10**：完全合格的决策必须零阻断**零警告**
- **E09**：干净的官方报价必须零发现
- **E06**：价格冲突是警告不是阻断
- **E13**：跨商品比价不得被判为冲突
- **P06/P08**：有汇率、有周期时，购买类结论必须能通过

`run_regression.py` 在 `expect_ok: true` 的审计用例上额外断言 `warnings == 0`——出现警告也算失败。

## 五、固定基准日

所有夹具把校验基准日固定为 `2026-10-29`（`FIXTURE_TODAY`）。否则半年后跑，所有价格都会被判"过期"，测试全红——那不是代码坏了，是测试写坏了。

CLI 冒烟测试则用**当天日期**生成证据，因为它走的是真实路径，要验证"今天取的价格能过"。

## 七、端到端

`run_cli_smoke.py` 用临时数据目录跑完整生命周期，23 步，验证：

- 数据目录能创建，且不在 Git 仓库内，仓库里没有个人数据文件
- 画像能写能读，可支配余额按"收入 − 支出 − 储蓄 − 投资"推算
- `profile gaps` 能列出待补字段
- 已有物品能登记能检索
- `judge` 一步完成判定与落账
- **18000 元被强制为不建议购买，且强制理由来自财务门**
- **外币缺汇率时拒绝落账**
- 账本能标记已购、记录复盘
- 统计能算出闲置率、后悔支出、高估倍数
- 审计不通过时拒绝落账

倒数第四条是本轮最重要的回归：它守着的正是审核报告里的第一项。

## 八、自然语言链路

`tests/natural-language-20261029.md` 记录了三个独立会话的真实调用测试。这一层没有自动化断言，因为输出是自然语言；它的作用是发现"只有跑全链路才暴露"的问题——事实上它确实抓到了一个（强制码标记被丢弃）。
