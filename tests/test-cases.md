# 测试用例说明

## 一、设计原则

每条用例都对应一个真实会发生的场景，不是为凑覆盖率编的。

判断一条用例好不好，问三个问题：

1. 这个场景真实存在吗？
2. 如果系统在这里出错，用户会受损吗？
3. 出错的表现是什么？能不能写成断言？

第 3 条最关键。写不成断言的，只能进人工回归清单。

**断言用精确匹配**：除了 `expect` 里列出的码，不允许出现别的阻断；确有合理附带项的，必须在 `allow` 里显式声明。v0.1 用的是"包含"断言，结果新加的阻断码可以悄悄出现而不被发现——审核为此扣了分。

合计 252 条。`fxguard` 与 `pageguard` 用 Python 直接构造用例，不写 JSON：

pipeline 是 v0.2 新增的一层，因为审核发现的十个问题里有六个**单模块测不出来**——它们是模块之间的接头处：财务算了但没人用、等级能被改、币种没归一、强制码被丢掉。

## 四、反向对照（防"一律拦截"）

一个永远输出"不建议购买"的系统也能通过所有拦截测试。所以：

- **V01/V02**：合格的享受型消费必须放行
- **A10**：完全合格的决策必须零阻断**零警告**
- **E09**：干净的官方报价必须零发现
- **E06**：价格冲突是警告不是阻断
- **E13**：跨商品比价不得被判为冲突
- **P06/P08**：有汇率、有周期时，购买类结论必须能通过
- **W7**：结余被高估但只吃掉 40% → 仍然可以买
- **W8**：结余被高估但存量拿得出 → 仍然可以买
- **A2/A21**：合格的替代品必须能给出 SWITCH，否则规则退化成"一律暂缓"
- **P34**：L2 但月结余覆盖得了 → 仍然可以买，不能因为等级低就一律降级
- **N5**：财务齐全、报价合格 → 必须给出 BUY，第六轮新增七条暂缓用例后仍要守住这一条
- **Q1/Q3**：替代品报价分别达到 `page` / `source` 级 → 必须给出 SWITCH
- **N14**：官方 900 + 社区 905 + 输入 900 → 必须给出 BUY（低可信报价不得干扰合格路径）
- **N18**：官网标价 1099 + 促销 899 + 输入 899 → 必须给出 BUY（口径感知不能做成"有两个报价就暂缓"）
- **N24**：替代品给了正文、正文里确有这个价 → 必须给出 SWITCH 且标 `content`（正文核验不能做成"一律不给替换建议"）
- **E27 / F14**：合法汇率 7.2 / 6.5 / 8.5 必须照常放行（汇率收紧 ≠ 外币一律不买）
- **E35 / G15**：正文里确有这个价时不得误报（正文核验不能做成"给了正文就一律拦"）
- **N15**：合法汇率（7.2）必须照常换算并允许购买（汇率收紧 ≠ 外币一律不买）
- **F10 / G6**：合法汇率与合法页面价必须照常通过
- **Q4**：已知限制固化——填一个页面上没有的数字，系统仍会判"页面核对过"（不是已修好的功能）

`run_regression.py` 在 `expect_ok: true` 的审计用例上额外断言 `warnings == 0`——出现警告也算失败。

## 五、固定基准日

所有夹具把校验基准日固定为 `2026-10-29`（`FIXTURE_TODAY`）。否则半年后跑，所有价格都会被判"过期"，测试全红——那不是代码坏了，是测试写坏了。

CLI 冒烟测试则用**当天日期**生成证据，因为它走的是真实路径，要验证"今天取的价格能过"。

这正是第五轮审核抓到的那类假阳性。

## 七、端到端

`run_cli_smoke.py` 用临时数据目录跑完整生命周期，44 步，验证：

- 数据目录能创建，且不在 Git 仓库内，仓库里没有个人数据文件
- 画像能写能读，可支配余额按"收入 − 支出 − 储蓄 − 投资"推算
- `profile gaps` 能列出待补字段
- 已有物品能登记能检索
- `judge` 一步完成判定与落账
- **18000 元被强制为不建议购买，且强制理由来自财务门**
- **外币缺汇率时结论降为暂缓，价格不进入预算；证据问题留在完整性门**
- **账本里没有外部伪造的 enforced，也没有外部自宣的预算码**
- **暂缓带复查条件可以落账；没写复查条件时拒绝落账**
- **存量未知时 18000 元只说「不知道」；存量确认为零才判不建议购买**
- **完全没有价格证据时结论是暂缓，`ok=True`，且不出现"买得起"这类承受力表述**
- **命令行路径下极端汇率同样不进计算**：结论暂缓、价格保持未知、报 `EV_FX_UNTRUSTED`
- 账本能标记已购、记录复盘
- 统计能算出闲置率、后悔支出、高估倍数

## 八、自然语言链路

`tests/natural-language-20261029.md` 记录了三个独立会话的真实调用测试。这一层没有自动化断言，因为输出是自然语言；它的作用是发现"只有跑全链路才暴露"的问题——事实上它确实抓到了一个（强制码标记被丢弃）。
